Privacy Policy (Gizlilik Politikası)

Last updated: 2026

This Chrome extension is designed to analyze performance metrics of websites built with Next.js and provide insights to developers.

Data Collection

This extension does not collect, store, or transmit any personal user data.

The extension only analyzes publicly available page information in order to detect performance-related signals for Next.js applications.

Data Usage

The extension processes page data locally in the browser to:

Detect if a website is built with Next.js

Measure basic performance indicators

Provide insights for developers

All analysis happens locally on the user's device.

Data Sharing

This extension does not share, sell, or transfer any user data to third parties.

Permissions

The extension may request permission to access the current webpage in order to analyze performance-related signals.

Changes

This privacy policy may be updated if the extension functionality changes.
